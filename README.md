# Employee Management System

Console app built in C# (.NET 9) to manage employees.

## Features
- Add, view, search, update, delete employees
- Calculate net salary (bonus 10%, tax 5%)
- Filter by department or salary above amount
- Save and load employees from a file
- Notification when an employee is added

## Concepts used
List, Dictionary, Generics, Exception handling, File handling,
Delegates (Func), Events, Extension methods

## How to run
1. Install the .NET SDK
2. cd src/EmployeeApp
3. dotnet run

## Project structure
- Employee.cs: data and rules
- EmployeeService.cs: logic
- EmployeeExtension.cs: helper methods
- Program.cs: menu
